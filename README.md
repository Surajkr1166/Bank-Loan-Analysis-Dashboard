# Bank Loan Analysis Dashboard

End-to-end loan portfolio analysis on 38,576 applications using Python, Pandas, and Plotly.

## Dataset
- 38,576 loan applications with 24 features
- Features: loan amount, interest rate, grade, employment, loan status, etc.

## What I Did
- Cleaned and preprocessed data — date parsing, type conversion, good/bad loan classification
- Calculated KPIs: 86.2% good loan ratio, $435M+ total funded, $473M+ total received
- Built monthly trend analysis for applications, funded amount, and received payments
- Visualized top 10 states by funded amount and top loan purposes using Plotly

## Tech Stack
Python, Pandas, NumPy, Plotly, Matplotlib, Seaborn

## Key Results
| KPI | Value |
|-----|-------|
| Total Applications | 38,576 |
| Total Funded | $435.7M |
| Total Received | $473M |
